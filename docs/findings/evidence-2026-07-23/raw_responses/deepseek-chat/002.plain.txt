## Attack Chain Reconstruction

### Stage 1: Initial Access & Execution
**Telemetry:** "dataset-loader process spawns a shell"

**Likely Attack Action:** 
An attacker has compromised the `dataset-loader` application (possibly via a vulnerable library, dependency confusion, or a crafted input file that exploits a parser vulnerability). The process executes a shell (e.g., `/bin/sh` or `cmd.exe`) to gain interactive or scripted command execution.

**Detection Opportunity (MITRE ATT&CK T1204/T1059):**
- **Process Tree Anomaly:** Alert on a known data-processing binary (e.g., `dataset-loader`) spawning an unexpected child process like `sh`, `bash`, `cmd.exe`, or `powershell`.
- **Command-line Argument Analysis:** Monitor for shell invocation with suspicious arguments (e.g., `-c`, `-enc`, base64-encoded commands, or commands involving `wget`, `curl`, or `nc`).
- **Behavioral Baseline:** Profile the normal behavior of `dataset-loader`. If it never spawns a shell in normal operation, this is a high-fidelity alert.

### Stage 2: Privilege Escalation / Credential Access
**Telemetry:** "worker node reads a credentials file"

**Likely Attack Action:**
Using the shell access, the attacker attempts to pivot or escalate privileges by reading a credentials file (e.g., `~/.ssh/id_rsa`, `/etc/shadow`, AWS keys, Kubernetes secrets, or service account tokens) from the worker node. This can enable lateral movement to other nodes or cloud resources.

**Detection Opportunity (MITRE ATT&CK T1552/T1003):**
- **File Access Monitoring:** Detect read attempts by non-admin processes on sensitive files (e.g., `.pem`, `.key`, `credentials.json`, `kubeconfig`, `shadow`).
- **Sensitive File Hashes:** Alert when a process with no legitimate need to read credentials (e.g., the spawned shell or `dataset-loader`) opens known credential store files.
- **Sysmon Event ID 11 (FileCreate) + 4663 (Attempt to access an object):** Look for a process tree that traces back to the anomalous shell accessing credential files.

### Stage 3: Exfiltration / Command & Control
**Telemetry:** "new outbound connection to host 10.0.0.5"

**Likely Attack Action:**
The attacker uses the stolen credentials or the access gained to establish a command-and-control (C2) channel or exfiltrate data. The destination `10.0.0.5` is a private IP, likely another compromised internal host, a staging server, or a secondary C2 relay. This could also represent lateral movement (e.g., `scp`, `rsync`, `curl`, or reverse shell) to that host.

**Detection Opportunity (MITRE ATT&CK T1041/T1571/T1021):**
- **Unusual Outbound Connections:** Alert on an outbound connection from the `dataset-loader` process or its child shell to a private IP address that is not part of the normal service mesh or allowed data pipeline.
- **Protocol Anomaly:** If the connection uses non-standard ports (e.g., SSH on port 443, HTTP on a high port, or raw TCP), flag it as suspicious.
- **Network Traffic Analysis:** Monitor for the volume or frequency of data being sent to `10.0.0.5`—especially if it follows immediately after the credential read.
- **Time-based Correlation:** Correlate the connection event with the preceding anomalous process behaviors within a short time window (e.g., <5 minutes).
